Agents built on large language models read tool outputs written for programs: most of what an API returns is never visibly reused in the agent's answer, yet it is paid for at every turn. In an exploratory study, we learn from an agent's own execution traces which fields of each tool output it visibly reuses, and remove the rest. On five agents (three on real APIs, two on simulated servers following public OpenAPI descriptions), a projection learned from seven runs and applied to an unseen one removed 63% and 70% of tool-output tokens on two of the agents with real APIs and 12% on the third, and 69% and 77% on the simulated ones (writing the same JSON compactly, with no field removed, already removes up to 13% and 17% respectively, and a full minifier up to 25% and 33%); in live runs with an expand tool for hidden fields, billed input tokens fell by 56% and 32%, and every run passed its gates, although a later re-check found one unsupported volume among 180 reported keyword–volume pairs. Learning only from tool calls, as a gateway would, missed a used field in 49% of the held-out structured calls it trims (156/317) on the three agents with real APIs, against 4% when learning from complete traces. Replays with projected outputs, under a protocol frozen in advance, located the failures precisely: values the agent transforms before writing them, fields it uses only to reason, and, without an identifier field, agents inventing identifiers. A second pre-registered study, on the same conversations, showed that two safeguards, keeping identifying fields and recognising transformed values, repaired those failures while keeping savings of 53% and 46% on those two real-API agents and 57% and 61% on the simulated ones, with the search-volume measures of the editorial plan (median; median and mean on the protocol's computable list) outside the raw arm's range; a post-hoc check found a fourth mechanism, translated values, not covered. We release the library, with a bilingual telemetry report and an MCP proxy that applies a reviewed projection in front of any server.
