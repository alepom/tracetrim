\section{Deviations from the protocols}
\label{app:deviations}

All are dated and explained in full in the repository's \texttt{protocol.md}; none was hidden or left unapplied.

\begin{enumerate}\setcounter{enumi}{-1}
\item A bug in the agent loop dropped the system prompt after the first turn; found in the pilot and fixed before
  Phase A. Pilot runs are excluded.
\item Prompts were written during the pilot rather than at freezing, and fixed before Phase A.
\item Tool-level caps made explicit: at most five results per literature search (amendment A2; this deviation had
  first set ten); a safety guard at 80 calls.
\item The literature catalogue was used without an API key, within its free daily allowance.
\item A verification pilot after the fix; one correction to the CI-triage gate (several job names per cause).
\item Simulated tools fixed before Phase A, with the OpenAPI versions and the presence rule documented.
\item Transport errors of the search-data server: retries reconnect; after three failures the agent receives an
  error and the run continues, flagged. Two editorial-plan runs of Phase A and two of Phase C (one per arm) are
  flagged; the results without them are reported in Section~\ref{sec:study1}.
\item The list of hidden fields shown with \texttt{expand} was grouped, largest groups first, before Phase C.
\item Post hoc: the literature-scan gate now requires a declared identifier to exist (it had accepted a valid DOI
  next to an invented identifier).
\item Phase C was delayed by a faulty resume script; no run was altered.
\item Post hoc: the CI-triage gate also splits job names on ``/''.
\item Post hoc: a strict test for one billing ticket, reported beside the frozen one; a defect in its pattern
  (it also accepted ``fondi sufficienti'') was fixed in the publication review, which changes one Phase A run.
\item Traces of the search-data cases are released as derived per-call records instead of pseudonymised traces,
  which could not have preserved the analysis.
\item Post hoc: the gates did not read projected outputs, which end with the line of hidden fields; the line is now
  cut and every Phase C run re-checked (no gate result changed). The editorial-plan volumes are also re-checked
  against the raw outputs of the other runs of the same day (Section~\ref{sec:phasec}).
\item Post hoc, publication review: usage compared by model turn. Calls emitted in one turn were compared by their
  position in the trace, so a later call's arguments could count as using an earlier sibling's output. Recomputed by
  turn, the detected usage changes in \TurnsCallsChanged{} of \TurnsCalls{} Phase A calls and every Study~1 figure is
  \TurnsFiguresUnchanged; the replay projections are identical.
\item Post hoc, publication review: thermometers and audits. The thermometers were implemented after the protocol was
  frozen and before Phase A, and differ from its list (C1 lacked the mean volume; its ``topics covered'' relied on the
  course's list of expected themes and cannot be computed here). H2 is also evaluated on the computable part of the protocol's list
  (Tables~\ref{tab:phaseb} and~\ref{tab:study2}), with the same outcome in every arm. The gates are narrower than the
  protocol's wording, and the billing thermometer is a keyword test: both are measured in
  Appendix~\ref{app:supplementary}.
\end{enumerate}

\section{Supplementary results}
\label{app:supplementary}

\paragraph{What the gates do not check.} Over all runs, the editorial-plan gate skipped \AuditCOneSkipped{} of
\AuditCOnePairs{} reported keyword--volume pairs (keywords without a volume in the run's outputs); in the content-gap
analysis \AuditCTwoDiffers{} of the \AuditCTwoFound{} cited results found in the search output carry a title different
from the one returned (the gate checks only the URL); in the literature scan \AuditCThreeDoi{} declared DOI differs from
the DOI of the work with that identifier. The literature-scan gate in its original form, before deviation 8, passed
the prudent, aggressive and structural arms of Phase B in \PhaseBOriginalGatesPrudentiii,
\PhaseBOriginalGatesAggressiveiii{} and \PhaseBOriginalGatesStructuraliii{} runs, against
\PhaseBNowGatesPrudentiii, \PhaseBNowGatesAggressiveiii{} and \PhaseBNowGatesStructuraliii{} with the corrected gate
(\texttt{experiments/gates\_audit.py}).
