\paragraph{Pre-registered hypotheses.} All four held as frozen. \emph{H5}: in billing support the \texttt{v02} arm
diagnosed all five tickets correctly in \StudyTwoFrozenAllRightVtwo{} runs, the period end included, where the
0.1 projection had lost it. \emph{H6}: in the literature scan every \texttt{v02} run passed the gates
(\StudyTwoVtwoGatesiii), so no identifier was invented; with 0.1 the prudent arm had passed in
\PhaseBPrudentGatesiii{} runs. \emph{H7}: in CI triage every \texttt{v02} run found all four expected links,
including the one lost in Phase B. \emph{H8}: the \texttt{v02} arm still removed \StudyTwoVtwoTokensi,
\StudyTwoVtwoTokensiii, \StudyTwoVtwoTokensiv{} and \StudyTwoVtwoTokensv{} of the tool-message tokens in the
editorial plan, the literature scan, billing support and CI triage, against \StudyTwoHeadroomTokensi, \StudyTwoHeadroomTokensiii, \StudyTwoHeadroomTokensiv{} and
\StudyTwoHeadroomTokensv{} for Headroom. The safeguards cost part of the saving (compare
\PhaseBPrudentTokensiii{} with \StudyTwoVtwoTokensiii{} in the literature scan) and bought back the three lost
pieces of information.

\paragraph{A fourth mechanism, found after the fact.} Reading the billing-support answers, we found that the
frozen test for one ticket was too lenient: it accepted the diagnosis when the word ``funds'' appeared anywhere in
the ticket, so advice such as ``check that you have sufficient funds'' passed it even when the diagnosis did not
give the reason for the declined payment. With a strict test on the diagnosis alone (added after the data were
seen, and reported beside the frozen result rather than instead of it), the raw arm gave the reason in
\StudyTwoStrictAllRightRaw{} runs and the \texttt{v02} arm in \StudyTwoStrictAllRightVtwo. The reason arrives as an
English sentence and the agent writes it in Italian: a \emph{translated} value, which neither usage detection nor
safeguard S2 recognises. The \texttt{v02} answers were not wrong (``the card was declined'') but less informative.

\paragraph{Format changes behaviour.} Cleaning and TOON encoding remove no information, yet adding them to the
\texttt{v02} projection changed answers. In the editorial plan the gates passed in \StudyTwoVtwostructuralGatesi{}
runs instead of \StudyTwoVtwoGatesi, each time on the same keyword: the search-volume tool, which the prompt names as
the source of all volumes, returned that keyword without a volume, while another tool gave one. With JSON the agent
used the other tool's figure; with the denser format it wrote zero. In billing support the arm had all tickets
right, under the frozen test, in \StudyTwoFrozenAllRightVtwostructural{} runs. The format did not hide data: it
shifted how the model resolved an ambiguity. The evidence is thin (one keyword, five runs), and the encoder is the
library's own minimal TOON-style implementation, not the reference one \citep{schopplich2026toon}; but it is a
reminder that a format the model reads less often is not a neutral choice, and its saving has to be validated like
any other change to what the agent reads.

\paragraph{The content-gap case.} The content-gap analyst failed the gates in most runs of every arm, the raw one
included (\StudyTwoRawGatesii): when the search API returns a redirect link instead of a result's URL, the agent
reconstructs the URL from the breadcrumb, against the instructions. The safeguards neither caused nor fixed this,
and the projection saves little on this task (\StudyTwoVtwoTokensii).
